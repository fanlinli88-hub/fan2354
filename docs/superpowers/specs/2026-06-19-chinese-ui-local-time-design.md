# WowVmMonitor 中文界面与本地时间设计

## 目标

- 将桌面窗口、状态、设置、异常历史、托盘菜单和用户可见错误提示汉化。
- 将日志修改时间和最近检测时间显示为 Windows 当前本地时区时间。
- 保持内部监控、超时、日志年龄和告警状态机继续使用 UTC/`DateTimeOffset` 计算。

## 问题根因

日志文件时间通过 `File.GetLastWriteTimeUtc` 正确读取为 UTC，日志年龄计算也正确。WPF 当前直接使用通用格式显示 `DateTimeOffset`，没有先转换到本地时区，因此北京时间 11:01 被显示为 UTC 03:01。截图中的 10 至 18 秒日志年龄证明检测数据是最新的，问题仅位于展示层。

## 方案

### 时间显示

- 新增展示层时间格式化器，将 `DateTimeOffset` 调用 `ToLocalTime()` 后格式化为 `yyyy-MM-dd HH:mm:ss`。
- `LastCompletedCheck` 和每台机器的 `LastWriteTime` 统一使用该格式化器。
- 缺少时间时显示 `--`。
- 不修改 `LatestLogLocator`、`SingleVmMonitor`、状态机或历史记录中的原始时间值。

### 中文界面

- 主标签页改为“监控状态”“设置”“异常历史”。
- 按钮、列标题、设置字段、历史提示和托盘菜单统一使用简体中文。
- 监控状态映射为“正常”“预警”“异常”“已恢复”“共享不可访问”“未找到日志”“检测错误”。
- 常见用户可见提示使用中文；底层异常详情保留原始文本，便于排查。

### 架构边界

- Core 和 Infrastructure 保持语言中立，不引入中文资源或本地时区转换。
- App/ViewModel 提供稳定的中文状态文本和可展示时间值。
- Desktop/XAML 只负责绑定和静态界面文案，不执行文件或网络操作。

## 测试

- 时间格式化测试：UTC 时间在本地时区下显示正确，空值显示 `--`。
- 状态映射测试：所有 `VmMonitorStatus` 均有明确中文文本。
- WPF 冒烟测试：中文标签、按钮和列标题能够加载。
- Release 全解构建，运行 App 定向测试和 Desktop 测试。

## 完成标准

- 截图中的 UTC 03:01 在中国标准时间环境显示为 11:01。
- 日志年龄与告警判断结果不发生变化。
- 用户日常操作界面不再出现英文按钮、标签或状态名称。
- UI 线程仍不执行耗时文件或网络操作。
